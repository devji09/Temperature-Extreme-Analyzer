# Temperature Extremes Analyzer

## Problem Statement

A project that identifies the minimum and maximum temperature readings within a selected period using the Divide and Conquer algorithm.

## Objectives

* Store temperature readings with dates or day labels.
* Find minimum and maximum temperatures using recursion.
* Track the number of comparisons performed.
* Compare Divide and Conquer with a linear approach.
* Display extreme temperatures with their corresponding dates or positions.

## Algorithm

The algorithm divides temperature readings into smaller ranges, finds the minimum and maximum in each range, and combines the results to determine the overall extremes.

## Complexity Analysis

* **Time Complexity:** O(n)
* **Auxiliary Space Complexity:** O(log n) for Divide and Conquer.

## Expected Output

Minimum and maximum temperatures, corresponding dates or positions, total readings analyzed, and comparison counts for both approaches.

## Conclusion

This project demonstrates the application of Divide and Conquer to temperature analysis and compares its performance with a straightforward linear approach.
